# Contact Creator Feature

## What It Does

Shows the creator's email on every resource card with a clickable mailto link.

## How It Works

```
Resource Card:
┌─────────────────────────────────────────┐
│  📄 Resource Title                       │
│  🔗 URL                                  │
│  📧 Contact creator: john@company.com    │ ← Click to email
└─────────────────────────────────────────┘
```

Click the email → Opens email client with pre-filled message

## Files Changed

1. **section-script.js** - Fetches creator email, displays contact link
2. **styles.css** - Styling for `.resource-contact` section
